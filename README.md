# ClínicaFlow

Sistema de gestão para clínicas médicas, desenvolvido
como projeto de estudo de C# e .NET.

## Sobre o projeto

O ClínicaFlow é um projeto educacional inspirado nas
funcionalidades de plataformas de gestão de clínicas,
como o OnDoctor.

O objetivo é desenvolver um MVP (Produto Mínimo Viável)
enquanto estudo os fundamentos da linguagem C#,
do ecossistema .NET e das boas práticas de desenvolvimento.

O ClínicaFlow é um projeto independente e não possui
vínculo com o OnDoctor.

## Funcionalidades previstas para o MVP

- Cadastro de clínicas
- Cadastro de profissionais
- Cadastro de pacientes
- Cadastro de serviços
- Gerenciamento de horários disponíveis
- Agendamento de consultas
- Controle de status dos agendamentos
- Autenticação de usuários

## Como executar o projeto

1. Clonar este repositório.
2. Abrir o arquivo doctor.slnx no Visual Studio.
3. Selecionar o projeto doctor.
4. Executar com Ctrl + F5.
